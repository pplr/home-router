# `aps/` — OpenWrt access points built from this repo

Same model as the router: **build artifact = source of truth**. The
whole fleet — every per-AP knob and every shared one — is declared in
[`config.toml`](config.toml). Secrets stay out-of-tree (see
[`secrets/README.md`](secrets/README.md)). A flash is `sysupgrade -n`
(overlay wipe) so on-device drift is impossible.

## Quick start

```bash
# 1. Populate aps/secrets/ — one-time per fresh checkout.
#    Read aps/secrets/README.md for the exact commands.

# 2. Build the image for one AP (or every AP in config.toml).
./aps/build.py ax3600
./aps/build.py r3g
./aps/build.py all

# 3. Transfer + flash.
scp aps/build/ax3600/out/*sysupgrade.bin root@10.0.0.2:/tmp/sysupgrade.bin
ssh root@10.0.0.2 'sysupgrade -n /tmp/sysupgrade.bin'   # -n = wipe overlay
# AP reboots; SSH back in once 10.0.0.X responds (~1–2 min).
```

If a flash bricks an AP, recover via OpenWrt failsafe mode (hold reset
on boot → 192.168.1.1) and re-flash a known-good image.

## Adding a new AP

1. Find the device on the live OpenWrt and capture three things:
   - **Model + target**: `ubus call system board` → `release.target` and `board_name`.
   - **Radio paths**: `uci show wireless | grep -E '\.path=|\.band=|\.htmode='`.
   - **Uplink port name**: `cat /etc/board.json` (look at `network.wan.device` or `network.lan.ports`).
2. Add a `[aps.<name>]` table to `config.toml` with `hostname`, `target`, `profile`, `version`, `sha256` (from `https://downloads.openwrt.org/releases/<version>/targets/<target>/sha256sums`), `management_ip`, optional `extra_packages`, and one `[[aps.<name>.radios]]` per physical radio (see existing entries).
3. `./aps/build.py --dump <name>` to confirm the parser accepts everything.
4. `./aps/build.py <name>` to build.

No new files in `aps/<name>/` to create — the per-AP directory is gone.

## Layout

| Path | Purpose |
|---|---|
| `config.toml` | Single source of truth: `[common]` + one `[aps.<name>]` per AP. |
| `build.py` | argparse entry point; loads `config.toml`, calls `apbuild.invoke.build_one`. Supports `--dump <ap>` to print the resolved spec as JSON without building. |
| `apbuild/` | Stdlib-only build driver (Python 3.10+; uses 3.14's `compression.zstd` or falls back to the `zstd` CLI). |
| `common/files/` | Overlay shared by every AP — only files with **no per-AP knobs** stay here (`/etc/config/{dropbear,dhcp}`, sysctl hardening). Everything else (`/etc/config/{system,network,wireless}`) is generated by `apbuild.render`. |
| `secrets/` | Gitignored — root hash, SSH host keys, Wi-Fi PSKs. See `secrets/README.md`. |
| `downloads/` | Gitignored — cached Image Builder tarballs. |
| `build/` | Gitignored — staged `FILES/` trees and output images. |

## `config.toml` structure (summary)

- **`[common]`** — `imagebuilder_base`, `timezone`, `zonename`, `country`.
- **`[common.router]`** — `ipv4`, `ipv6`, `lan_v6_prefix` used to generate the AP's static IP defaults and DNS.
- **`[common.syslog]`** — Where logd ships logs (the router runs an rsyslog→journald collector).
- **`[common.uplink]`** — DSA trunk port name (`wan` on both Xiaomi devices) and IoT VLAN ID.
- **`[common.packages].add` / `.remove`** — Image Builder `PACKAGES=` shared by every AP (`-foo` removes).
- **`[common.ssids.<key>]`** — One VAP definition broadcast on every non-disabled radio of every AP. Visible name is `name`; PSK file path is `psk_secret` (resolved under `aps/secrets/`).
- **`[aps.<name>]`** — Per-AP: `host` (→ `hostname`/`management_ip` from `hosts.toml`), `target`, `profile`, `version`, `sha256`, optional `extra_packages`, and optional `netdata` (bool). `netdata = true` pulls in the `netdata` package and generates `/etc/netdata/stream.conf` so the AP streams its metrics to the router's netdata parent (`10.0.0.1:19999`); requires the shared `netdata/stream_api_key` secret on both the AP and the router. Only enable on APs with RAM/flash headroom (not the r3g).
- **`[[aps.<name>.radios]]`** — Ordered radio array; index becomes `radio0/1/2/...` in the generated `/etc/config/wireless`. Set `disabled = true` to emit a wifi-device entry with `option disabled '1'` and skip its VAPs.

Strict schema: unknown keys raise `ConfigError` (e.g. `[aps.ax3600]: unknown keys: ['frobnicate']`). Typos can't silently no-op.

## Pinned versions

Both APs pin **OpenWrt 25.12.0**. Sha256 is verified against the value in `aps.<ap>.sha256`. To bump: edit `version` and `sha256` (from `https://downloads.openwrt.org/releases/<version>/targets/<target>/sha256sums`) in `config.toml`, then `./aps/build.py <ap>`.

In 25.12, OpenWrt renamed the IPQ807x target from `ipq807x/generic` to
`qualcommax/ipq807x` (the chip family is now grouped under
`qualcommax`). The R3G's `ramips/mt7621` is unchanged.
