# `aps/` — OpenWrt access points built from this repo

Same model as the router: **build artifact = source of truth**. The
whole fleet — every per-AP knob and every shared one — is declared in the
repo-root [`config.toml`](../config.toml), which also carries the router
and the non-AP devices. Secrets stay out-of-tree (see
[`secrets/README.md`](secrets/README.md)). A flash is `sysupgrade -n`
(overlay wipe) so on-device drift is impossible.

## Quick start

```bash
# 1. Populate aps/secrets/ — one-time per fresh checkout.
#    Read aps/secrets/README.md for the exact commands. This includes
#    ./aps/gen-ap-tls.py, which mints the per-AP LuCI TLS key + CSR.

# 2. Build the image for one AP (or every AP in config.toml).
./aps/build.py ax3600
./aps/build.py r3g
./aps/build.py all

# 3. Transfer + flash.
scp aps/build/ax3600/out/*sysupgrade.bin root@10.0.0.2:/tmp/sysupgrade.bin
ssh root@10.0.0.2 'sysupgrade -n /tmp/sysupgrade.bin'   # -n = wipe overlay
# AP reboots; SSH back in once 10.0.0.X responds (~1–2 min).
```

If a flash bricks an AP, recover via OpenWrt failsafe mode (hold reset
on boot → 192.168.1.1) and re-flash a known-good image.

## Adding a new AP

1. Find the device on the live OpenWrt and capture three things:
   - **Model + target**: `ubus call system board` → `release.target` and `board_name`.
   - **Radio paths**: `uci show wireless | grep -E '\.path=|\.band=|\.htmode='`.
   - **Uplink port name**: `cat /etc/board.json` (look at `network.wan.device` or `network.lan.ports`).
2. Add an `[aps.<label>]` table to the **repo-root `config.toml`** with `hostname`, `ipv4`, optional `cert`, `target`, `profile`, `version`, `sha256` (from `https://downloads.openwrt.org/releases/<version>/targets/<target>/sha256sums`), optional `extra_packages`, and one `[[aps.<label>.radios]]` per physical radio (see existing entries).
3. `./aps/build.py --dump <label>` to confirm the parser accepts everything.
4. `./aps/build.py <label>` to build.

The table key **is** the AP's identifier — no separate `[[hosts]]` entry, and no
per-AP directory under `aps/`.

## Layout

| Path | Purpose |
|---|---|
| `../config.toml` | Single source of truth for the whole network, including `[aps]` + one `[aps.<label>]` per AP. |
| `build.py` | argparse entry point; loads `../config.toml`, calls `apbuild.invoke.build_one`. Supports `--dump <ap>` to print the resolved spec as JSON without building. |
| `apbuild/` | Stdlib-only build driver (Python 3.10+; uses 3.14's `compression.zstd` or falls back to the `zstd` CLI). |
| `common/files/` | Overlay shared by every AP — only files with **no per-AP knobs** stay here (`/etc/config/{dropbear,dhcp}`, sysctl hardening, `usr/libexec/accept-ap-cert.sh`). Everything else (`/etc/config/{system,network,wireless,uhttpd}`) is generated by `apbuild.render`. |
| `gen-ap-tls.py` | Generates the per-AP LuCI TLS key + CSR + bootstrap cert into `secrets/tls/`. Run once per AP (and again with `--force` to rotate). |
| `secrets/` | Gitignored — root hash, SSH host keys, Wi-Fi PSKs. See `secrets/README.md`. |
| `downloads/` | Gitignored — cached Image Builder tarballs. |
| `build/` | Gitignored — staged `FILES/` trees and output images. |

## `config.toml` structure (AP-relevant summary)

The APs live in the repo-root `config.toml` alongside `[router]`, `[acme]` and
`[[hosts]]`. Under `[aps]`, **any key whose value is a table is an access point**;
scalars and arrays are fleet-wide settings. That is why the shared settings are flat
and SSIDs are an array-of-tables — a nested `[aps.syslog]` would be
indistinguishable from an AP labelled `syslog`.

- **`[aps]`** — fleet-wide: `imagebuilder_base`, `timezone`, `zonename`, `country`,
  `syslog_port` / `syslog_proto`, `trunk_port_alias` (DSA trunk port, `wan` on both
  Xiaomi devices), `iot_vlan`, and `packages_add` / `packages_remove` (Image Builder
  `PACKAGES=` shared by every AP; `-foo` removes).
- **`[[aps.ssids]]`** — one VAP definition broadcast on every non-disabled radio of
  every AP. `key` names the generated UCI section, `name` is the visible SSID, and
  `psk_secret` is a path under `aps/secrets/`.
- **`[aps.<label>]`** — per-AP identity **and** build spec: `hostname`, `ipv4`,
  optional `cert` (opt into the centrally-issued LuCI certificate), `target`,
  `profile`, `version`, `sha256`, optional `extra_packages`. Metrics are pull-based:
  every AP runs `prometheus-node-exporter-lua` on `:9100` (from `packages_add`),
  scraped by the router's VictoriaMetrics — no per-AP monitoring toggle.
- **`[[aps.<label>.radios]]`** — ordered radio array; index becomes `radio0/1/2/...`
  in the generated `/etc/config/wireless`. Set `disabled = true` to emit a
  wifi-device entry with `option disabled '1'` and skip its VAPs.

The AP's gateway, DNS, NTP server and syslog target are **derived** from
`[router].lan_ipv4` rather than repeated, so they cannot drift.

Strict schema: unknown keys raise `ConfigError` (e.g. `[aps.ax3600]: unknown keys: ['frobnicate']`). Typos can't silently no-op.

## Pinned versions

Both APs pin **OpenWrt 25.12.0**. Sha256 is verified against the value in `aps.<ap>.sha256`. To bump: edit `version` and `sha256` (from `https://downloads.openwrt.org/releases/<version>/targets/<target>/sha256sums`) in `config.toml`, then `./aps/build.py <ap>`.

In 25.12, OpenWrt renamed the IPQ807x target from `ipq807x/generic` to
`qualcommax/ipq807x` (the chip family is now grouped under
`qualcommax`). The R3G's `ramips/mt7621` is unchanged.
